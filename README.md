# じしょ — 自分だけの辞書アプリ

ブラウザだけで動く、かんたんに自分の辞書を作れるアプリです。インストールもサーバーも不要で、`index.html` を開くだけで使えます。

## できること

- ことばの登録・編集・削除（見出し語、読み、意味、例文・メモ、タグ）
- インクリメンタル検索（ひらがな／カタカナ、全角／半角、大文字／小文字を区別せずに探せる。一致した部分はハイライト）
- 並び替え（五十音順は「あ行」「か行」…で見出しつき、新しい順、古い順、更新順）
- タグで絞り込み
- 辞書を複数作って切り替え（「英単語」「IT用語」「専門用語」など）
- JSON でまるごとバックアップ・復元、CSV で書き出し・読み込み（CSV は BOM つきなので Excel でもそのまま開ける）
- ダークモード対応、スマホ対応
- ショートカット：`/` で検索、`n` で追加、検索欄で `Esc` を押すとクリア

## 使い方

ローカルで使うなら `index.html` をブラウザで開くだけ。

GitHub Pages で公開する場合は、リポジトリの **Settings → Pages** で Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存すると、`https://honmasatoko.github.io/app-jisyo/` で使えるようになります。

## データの保存場所

データはブラウザの localStorage に保存され、外部には送信されません。そのぶん、ブラウザのデータを消したり別の端末に移ったりすると見えなくなるので、ときどき「JSONで書き出す」でバックアップしてください。別の端末へは、書き出した JSON をその端末で「読み込む」と移せます。

## CSV の形式

1行目は見出し行（省略可）で、列の順番は次のとおりです。タグは空白で区切ります。

```csv
見出し語,読み,意味,例文・メモ,タグ
冪等,べきとう,何回実行しても結果が同じになる性質,"PUT は冪等、POST は冪等ではない",IT用語 HTTP
```
